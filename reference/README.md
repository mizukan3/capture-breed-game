# 参照資料の受け渡し先

次の原本をここへ追加すると、会話の添付を直接開けない開発環境でもGitHub経由で解析できます。

- 会話に添付したcapture-breed-first-dungeon-v0.23.14のHTML
- 会話に添付したモンスターリスト最新版v62のテキスト

アップロードされたファイル名に(9)、(2)などが付いていても、そのままで構いません。
元ファイルの内容を変更する必要はありません。

現在のnative/data/provenance.jsonは、既存index.htmlのgit blobを参照しています。
新しい原本を受け取り次第、まず旧参照との同一性/差分を検査し、
データ、計算式、機能表、原版照合の参照先を更新して本体移植へ進めます。
